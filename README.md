# PROGI_PROJEKT
Informacijski sustav za charter poslovanje (najam plovila). Timski projekt na predmetu Programsko inženjerstvo.

## Poveznice

| Poveznica | Opis |
| --- | --- |
| [Web aplikacija](https://progiprojekt.vercel.app) | Početna stranica aplikacije postavljene na Vercelu. |
| [API dokumentacija](https://progiprojekt.vercel.app/api/docs) | Swagger pregled dostupnih API ruta i mogućnost slanja probnih zahtjeva. |
| [Provjera backenda](https://progiprojekt.vercel.app/api/health) | Provjera radi li FastAPI backend. |
| [Provjera veze s bazom](https://progiprojekt.vercel.app/api/health/db) | Provjera može li se backend povezati sa Supabase bazom i izvršiti jednostavan SQL upit. |
