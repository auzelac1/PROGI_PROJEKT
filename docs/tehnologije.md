### **Frontend**
•	**React**: Omogućuje izradu sučelja kroz višekratno iskoristive komponente.
•	**Vite**: Osigurava brzu izgradnju projekta.
•	**Bootstrap**: Jamči responzivnost i prilagodbu sučelja svim uređajima (računala, tableti, pametni telefoni).
### **Backend**
•	**Python i FastAPI**: Odabrani jer tim dobro poznaje Python; FastAPI je idealan za brzu izradu REST API-ja i automatski generira Swagger dokumentaciju.
### **Baza podataka i pohrana**
•	**PostgreSQL (Supabase)**: Pouzdana relacijska baza s kojom članovi tima već imaju iskustva, a Supabase nudi besplatan hosting u oblaku.
### **Infrastruktura i servisi**
•	**Hosting (Vercel)**: Besplatna platforma s automatskim povezivanjem na GitHub repozitorij i uključenim HTTPS certifikatom.
•	**Karta (OpenStreetMap + React-Leaflet)**: Besplatno i open-source rješenje jednostavno za integraciju u React.
•	**Vremenska prognoza (Open-Meteo API)**: Besplatan servis bez potrebe za API ključem, koji nudi pouzdane prognoze do 16 dana unaprijed.
•	**Prijava (Google OAuth 2.0 / OpenID Connect)**: Siguran sustav prijave bez pohranjivanja lozinki, uz delegiranje provjere identiteta vanjskom pružatelju.
